Google 發布 Gemini 4 Hydrogen 模型，已整合至 Search 免費使用並開放 API

Google DeepMind 推出 Gemini 4 Hydrogen，定位快速執行日常編碼與代理任務，已向全球 Search 用戶開放並支援 API 呼叫，與 Argon、Carbon 同屬 Gemini 4 系列。DeepSeek 將 App 對話能力開放給開發者 API，包含聯網搜尋、檔案輸入與連結閱讀。NVIDIA 領導層變動未直接影響模型發布，但市場關注算力供應穩定性。HuggingFace 上 Qwen 與 DeepSeek 相關模型持續高下載量，Polymarket 顯示 Google 模型領先機率仍高。

  • Google 發布 Gemini 4 Hydrogen 模型，支援 100 萬 token 多模態上下文，速度提升 2-2.8 倍，高階版本基準分數 54，已整合 Search 免費使用並有 API 定價 ▸這是 Gemini 4 系列針對代理與編碼的實用模型，已實際落地 Search 與第三方工具（如 Cursor），提供獨立第三方驗證的可用性，而非僅預告
  • DeepSeek 開放 API 額外功能，開發者可啟用聯網搜尋、檔案輸入、閱讀連結等，工具呼叫由服務端處理 ▸將先前 App 專屬能力開放給開發者，降低代理應用開發門檻，代表實際可用的 API 進展而非僅模型權重更新
  • OpenAI 將機器人研究團隊併入主研究，轉用 GPT-6 Astra 直接控制機器人，計劃 2027 年人形機器人 demo ▸顯示通用模型已足夠驅動機器人控制，從專用硬體模型轉向代理控制的實質策略調整
⚠️ NVIDIA 領導層變動被廣泛討論，但公告未提及 GPU 路線圖或供應改變，部分報導可能過度解讀為產業危機
