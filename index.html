OpenAI GPT-Live-1.1 正式開放 API 並新增待機模式，將語音代理閒置成本降至每分鐘 0.02 美元

過去 24 小時內，OpenAI 將已在 ChatGPT 使用的 GPT-Live-1.1 推向 API，支援 WebRTC 待機模式並維持 $0.05 活躍費率，開發者可設定 5-60 秒閒置逾時後暫停推論。Thinking Machines Lab 於 11 月 20 日釋出 Inkling 2 Mini 開源權重（26.4B 總參數、3.4B 活躍、迴圈中間層三次），已在 Hugging Face 累積數千下載與實測反饋，適合筆電運行且在 agentic coding benchmarks 領先同級。Polymarket 仍顯示 Google 模型領先，但無直接對應新模型發布；HF 趨勢與 X 實測貼文一致指向 Inkling 2 Mini 的實際可用性。

  • OpenAI 將 GPT-Live-1.1 開放至 API（模型 ID gpt-live-1.1），新增 WebRTC 待機模式，閒置費率從 $0.05 降至 $0.02/分鐘，並改善多語言口音、一致性與精確細節處理（如字母數字）。 ▸這是生產級語音代理的實質成本降低（60% 閒置折扣），搭配可委派後端模型的指令，跟隨功能，讓企業部署 always-on voice agent 的經濟可行性大幅提升，已有官方 changelog 與多方報導確認非預告。
  • Thinking Machines Lab 釋出 Inkling 2 Mini 開源權重（Apache 2.0），26.4B 總參數 MoE、3.4B 活躍參數、中間層迴圈三次，~20GB 記憶體 footprint，在 DeepSWE v1.1 等 agentic coding benchmarks 領先同級開放模型。 ▸這是真正可在本機筆電/32GB Mac 運行的 agentic coding 強力小模型，已有 Unsloth GGUF 與實測 tok/s 數據，HF 下載與 X 工程師貼文顯示立即可用，非僅公告，改變開放模型在 agent 場景的競爭格局。
  • @OpenAIDevsGPT-Live-1.1 現已開放 API，支援待機模式與後端委派，改善精確細節理解與指令遵循。
  • @ManyGlue在 RTX 3090 上實測 Inkling 2 Mini 自製引擎，115 tok/s decode、支援 262k context 與 vision。
