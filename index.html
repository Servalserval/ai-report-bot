Anthropic 發布 Claude Fable 5.2 與 Sonnet 5.5，Fable 5.2 在多項 benchmark 領先 Opus 5.5

Anthropic 於 11 月 9 日正式推出 Fable 5.2 與 Sonnet 5.5，Fable 5.2 在 Vals Index 與部分 coding benchmark 取得領先分數。獨立評測如 ToolColumn 與 Vals AI 顯示其在 agentic coding 與知識任務上具優勢，但成本與 thinking tokens 設定需注意。Polymarket 顯示 Anthropic 勝率上升，反映市場對此更新的正面反應。HuggingFace 與 Venice 上架訊號確認模型已可實際使用。官方 benchmark 需獨立複現驗證，尤其安全機制與 distillation 防護的實際效果。

  • Anthropic 發布 Claude Fable 5.2 與 Mythos 5.2，Fable 5.2 在 Vals Index v2.2 拿下 71.31% 領先 Sonnet 5.5 的 70.85%。 ▸這是公開可用模型中能力最強的更新，直接影響 coding 與 agent 工作流程的選擇，Fable 版本已上架 Venice API 確認可實際呼叫。
  • ToolColumn 與 benchlm.ai 比較顯示 Sonnet 5.5 coding 分數高於 Fable 5.2，但 Fable 在特定 agentic 任務具優勢，Opus 5.5 仍為 coding 性價比首選。 ▸不同 benchmark 結果互有領先，提醒使用者需依 workload 測試成本與實際完成任務效率，而非單看公開分數。
  • Anthropic 官方指出 Fable 5.2 具最強 distillation 防護，Mythos 5.2 在 cybersecurity 任務表現優於前代。 ▸這改變安全模型的部署策略，Fable 版限制安全相關任務，影響開發者選擇與合規考量。
⚠️ Anthropic 官方 benchmark 與第三方評測結果偶有差異，需等待獨立複現；Fable 5.2 安全限制可能被視為公關包裝。
